# Lab2Web — Praktikum HTML Lanjutan

Website sederhana untuk latihan HTML lanjutan, berisi tabel data mahasiswa, tabel nilai praktikum, formulir registrasi, biodata mahasiswa, serta contoh elemen audio dan video.

## Struktur proyek

```text
Lab2Web/
├── index.html       # Beranda, data mahasiswa, nilai, form, multimedia
├── biodata.html     # Halaman biodata mahasiswa
├── style.css        # Tampilan responsif untuk semua halaman
├── media/
│   └── README.txt   # Petunjuk menambahkan file multimedia
└── README.md        # Dokumentasi proyek
```

## Cara menjalankan

1. Unduh atau clone repository ini.
2. Buka folder `Lab2Web`.
3. Klik dua kali `index.html`, atau buka melalui browser.
4. Gunakan menu **Biodata** untuk membuka `biodata.html`.

## Multimedia

Agar pemutar media berfungsi, letakkan file berikut di folder `media/`:

- `audio.mp3`
- `video.mp4`

File multimedia tidak disertakan karena perlu diisi dengan file milik sendiri.

## Catatan

- Data mahasiswa yang tampil adalah data contoh. Sesuaikan dengan data tugas kamu sebelum dikumpulkan.
- Formulir memakai validasi browser dan menampilkan pesan demo. Data belum dikirim atau disimpan ke server.
- Website menggunakan HTML, CSS, dan JavaScript sederhana tanpa framework.

## Publikasi dengan GitHub Pages

1. Unggah semua file dan folder ke repository GitHub.
2. Buka **Settings → Pages**.
3. Pada bagian **Build and deployment**, pilih **Deploy from a branch**.
4. Pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
5. Tunggu proses publikasi selesai; alamat website akan muncul di halaman Pages.
